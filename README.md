# পাবনা বাস গাইড — Pabna Bus Transit Guide

পাবনা জেলার সব বাস, রুট, বাস কোম্পানি, লোকাল ও দূরপাল্লার রুট, জেলা অতিক্রমকারী বাস, বাস কাউন্টার এবং যোগাযোগের তথ্যের পূর্ণাঙ্গ বাংলা ডিজিটাল ডিরেক্টরি ও ম্যানেজমেন্ট প্ল্যাটফর্ম।

---

## 🌟 প্রধান বৈশিষ্ট্যসমূহ (Features)

১. **সম্পূর্ণ বাংলা ইউজার ইন্টারফেস ও SolaimanLipi ফন্ট**:
   - খাঁটি বাংলা টাইপোগ্রাফি ও অফলাইন WOFF ফন্ট লোডিং।
   - বাংলা ও ইংরেজি উভয় ভাষায় দ্বৈত সার্চ ও বাংলা সংখ্যা (০-৯) হ্যান্ডলিং।

২. **পাবনা অতিক্রমকারী বাস (Pabna Crossing Corridor)**:
   - পাবনার বাইরে থেকে শুরু হয়ে জেলা অতিক্রমকারী বাসগুলোর বিশেষ তথ্য।
   - পাবনায় প্রবেশের স্থান, ট্রানজিট স্টপ (দাশুড়িয়া মোড়, পাকশী সেতু), এবং যাত্রী ওঠানামার নিয়মাবলী।

৩. **সত্যায়িত কাউন্টার ও সরাসরি কল ডিরেক্টরি**:
   - পাবনা সদর, ঈশ্বরদী, সাঁথিয়া, বেড়া, চাটমোহরসহ সকল উপজেলার কাউন্টারের ফোন নম্বর।
   - যাচাইকৃত নম্বরের ব্যাজ ও গুগল ম্যাপ লোকেশন।

৪. **ইন্টারঅ্যাক্টিভ ওপেনস্ট্রিটম্যাপ (OpenStreetMap / Leaflet)**:
   - পাবনা ট্রানজিট রুটের স্টপেজ ও স্টেশন মার্কার।

৫. **সম্পূর্ণ কার্যকর অ্যাডমিন ম্যানেজমেন্ট প্যানেল (/admin)**:
   - কোড পরিবর্তন ছাড়াই নতুন বাস, রুট, কোম্পানি ও কাউন্টার যোগ, সম্পাদনা, প্রকাশ, খসড়া ও ডিলিট করার সুবিধা।
   - ১৯ টি পূর্ণাঙ্গ ফিল্ডসহ বাস এন্ট্রি ও স্টপেজ রি-অর্ডারিং।
   - যাত্রীদের পাঠানো ভুল তথ্য সংশোধনের অনুরোধ পর্যালোচনা ও সমাধান।
   - CSV ও JSON ডেটা আমদানি এবং ব্যাকআপ রপ্তানি।
   - সিস্টেমের প্রতিটি অ্যাকশনের স্বয়ংক্রিয় অডিট লগ (Audit Log)।

## 🚀 লোকাল রান করার নিয়মাবলী

```bash
# ১. ডিপেনডেন্সি ইনস্টল করুন
npm install

# ২. ডেভেলপমেন্ট সার্ভার চালু করুন (Port 3000)
npm run dev

# ৩. প্রোডাকশন বিল্ড তৈরি করুন
npm run build
```

## ☁️ GitHub ও Vercel এ ডেপ্লয়মেন্ট নির্দেশিকা

### ১. GitHub এ কোড আপলোড
```bash
git init
git add .
git commit -m "Initial commit of Pabna Bus Guide"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/pabna-bus-guide.git
git push -u origin main
```

### ২. Vercel এ ডেপ্লয়মেন্ট
১. [Vercel Dashboard](https://vercel.com)-এ যান এবং `Add New Project` সিলেক্ট করুন।
২. আপনার GitHub রিপোজিটরিটি ইমপোর্ট করুন।
৩. Framework Preset হিসেবে `Vite` বা `Other` নির্বাচন করুন।
৪. Build Command: `npm run build`
৫. Output Directory: `dist`
৬. Environment Variables কনফিগার করুন:
   - `ADMIN_SESSION_SECRET`: আপনার তৈরি একটি শক্তিশালী সিক্রেট কি
   - `PORT`: `3000`

### ৩. PostgreSQL / Supabase ডেটাবেস সংযোগ (ঐচ্ছিক এক্সটার্নাল মাইগ্রেশন)
প্রজেক্টের রুট ডিরেক্টরিতে `database/schema.sql` ফাইলটি দেওয়া আছে। Supabase বা Neon SQL এডিটরে এই ফাইলটির কোড পেস্ট করে রান করলেই সম্পূর্ণ রিলেশনাল টেবিল স্ট্রাকচার প্রস্তুত হয়ে যাবে।
